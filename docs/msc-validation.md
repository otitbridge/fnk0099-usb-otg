# MSC検証結果

検証日：2026-11-17。FNK0099 Rev 1.1 / N16R8、カードリーダー `14cd:1212`、microSD 1GB / FAT16、Macの組合せで、当初計画の7項目をすべて完了しました。操作方法は[MSC操作手順](msc-usage.md)、各時点の詳細は[経過記録](history/msc-validation-2026-11-17.md)を参照してください。

## 7項目の結果

| 番号 | 検証内容 | 結果 |
|---|---|---|
| 1 | USB認識・記述子取得 | MSC / Transparent SCSI / BOT、Bulk IN・OUTを確認 |
| 2 | MSC専用環境の実装・ビルド | MSC・既存HID環境ともビルド成功、コンパイラーの警告・エラーなし |
| 3 | 実機書き込み・メディア情報・マウント | アップロードのハッシュ検証、MSC初期化、容量取得、マウント成功 |
| 4 | 既知ファイル読み取り | Macで準備した `PROBE.TXT` の30バイト・内容・SHA-256一致 |
| 5 | 小さいファイルの新規書き込み | `WRITE.TXT` の31バイトを新規作成。同期・クローズ直後と再マウント後に内容・SHA-256一致 |
| 6 | 1MiB書き込み・保持・Mac照合 | `BULK1M.BIN` の作成直後・再マウント後にサイズ・SHA-256一致。Macで3ファイルを独立照合 |
| 7 | 安全な取り外し・再接続3回、RESET3回 | 全6試行で再認識・3ファイル照合成功。警告・エラー・パニックなし |

旧経過記録では、現在の3・4番をまとめた6段階表記を使っていました。本書は当初計画の7項目に統一しています。

## 機材と実行ファーム

| 項目 | 記録 |

| 実機試験アプリBIN | 345,808バイト |

| USB | Full-Speed 12Mbps、IF0、class/subclass/protocol `08/06/50` |

BINはコミット前に生成した実機試験物です。コミット後の再ビルドでは埋め込み版情報などによりハッシュが変わる場合があります。容量は各層の観測値をそのまま記載しています。

## ファイル照合と所要時間

検証データの定義・SHA-256は[MSC操作手順の検証データ](msc-usage.md#検証データ)を参照してください。

| 操作 | 実測 |
|---|---|
| 31バイト作成から同期・クローズ・再オープン照合まで | 10ms |
| 31バイトの再マウント後の照合 | 4ms |
| 1MiBのパターン生成・書き込み・同期・クローズ | 1,168ms |
| 1MiBの直後の読み取り・SHA-256照合 | 1,595ms |
| 1MiBの再マウント後の読み取り・SHA-256照合 | 1,583ms |

時間はUSB転送以外の処理を含む参考値です。Mac側では3ファイルを読み取り専用で開き、小さい2ファイルは公開フィクスチャとの完全一致、1MiBは独立したPythonパターンとの全バイト一致、各サイズ・SHA-256を確認して安全に取り外しました。

## 再接続・RESETの最終試験

UARTを開いたままユーザーが物理操作を行い、各回の前にアンマウント、再認識後に `read`・`verify-write`・`verify-1m`、最後にアンマウントを実行しました。再接続ではUART給電を維持してOTG側だけを抜き差しし、RESETでは両USBを保持して基板のRESETボタンを押しました。

| 試行 | 3ファイル照合 | 1MiB照合 | マウント中の空きヒープ | アンマウント後の空きヒープ |
|---|---|---|---|---|
| 再接続1 | 成功 | 1,592ms | 334,568バイト | 355,860バイト |
| 再接続2 | 成功 | 1,587ms | 334,568バイト | 355,860バイト |
| 再接続3 | 成功 | 1,592ms | 334,568バイト | 355,860バイト |
| RESET1 | 成功 | 1,593ms | 335,056バイト | 355,860バイト |
| RESET2 | 成功 | 1,592ms | 335,056バイト | 355,860バイト |
| RESET3 | 成功 | 1,592ms | 335,056バイト | 355,860バイト |

再接続群・RESET群それぞれで同じ状態の空きヒープは一定でした。全6試行で警告・エラー・パニック・復帰不能・照合不一致はなく、最終状態は `device=1 mounted=0 cleanup_failed=0` です。UART取得は正常終了し、ポートを閉じました。

準備時の操作間違いによるタイムアウトは、試行成立0回として上記6試行から除外しています。[公開結果JSON](evidence/msc-reconnect-reset-2026-11-17.json)に各試行のハッシュ・時間・ヒープと除外理由を記録しています。

## 完了範囲と残る制約

今回の組合せでファイル読み書き・再マウント・Mac照合・安全な抜き差し・RESET後の保持を確認しました。長時間連続稼働、書き込み中の抜去、電源断耐性、全容量への書き込み、別のカードリーダー・SD・ファイルシステムは未検証です。RESET試験を電源断試験として扱いません。

既存ファイルの上書き・削除・フォーマットは実施していません。同期APIの範囲と切り分けは[既知の制約](known-issues.md#mscの適用範囲と同期)を参照してください。ホストOS上のテストは[ビルド手順](build.md#mscファイル操作のホストテスト)に記載しています。生ログ・ローカル操作補助・機器固有情報はGit対象外の `.local/msc-validation/` に保持しています。
